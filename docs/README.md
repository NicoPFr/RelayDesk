# RelayDesk documentation

[← RelayDesk](../README.md)

RelayDesk combines local terminals, SSH sessions, and remote files in a macOS workspace. [RelayDesk 2.11.0 is available](https://github.com/NicoPFr/RelayDesk/releases/tag/v2.11.0) for macOS.

| Guide | What you will find |
| --- | --- |
| [Installation](installation.md) | Download, installation, compatibility, and signing status. |
| [First steps](first-steps.md) | Local terminals, SSH connections, remote files, and organizing sessions. |
| [Local data and privacy](privacy.md) | What RelayDesk stores locally and what to remove before sharing a report. |
| [Release status](releases.md) | Published versions, validation coverage, and the download convention. |

The current interface is primarily in French. English and French are welcome in [GitHub Issues](https://github.com/NicoPFr/RelayDesk/issues).
