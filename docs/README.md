# RelayDesk documentation

[← RelayDesk](../README.md)

RelayDesk brings local terminals, SSH, and remote files into one macOS workspace. This documentation area will hold the user guides for the public application.

## Before you get started

- **Availability:** public distribution is coming soon. There is no public application download yet.
- **Platform:** RelayDesk is a macOS application. The supported macOS versions and hardware requirements for the first public release will be confirmed in its release notes.
- **Language:** the current application interface is primarily in French. Broader interface localization is planned; this repository's English presentation does not imply a fully localized English application.
- **Accounts:** core terminal and SSH workflows do not require a cloud account.
- **Pricing and ownership:** RelayDesk is proprietary software, free to use. Application source code is not distributed in this repository.
