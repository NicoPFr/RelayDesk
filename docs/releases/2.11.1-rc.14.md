# RelayDesk 2.11.1-rc.14 — macOS prerelease

This is an experimental release candidate, not a stable release.
Maintained by [@NicoPFr](https://github.com/NicoPFr).

## Changes

- Updated application dependencies and Go runtime with security fixes.
- Fixed paste followed immediately by Enter: the terminal preserves input order while reading the clipboard.
- Protected recognized sensitive prompts from command-history recording and shared-input routing.
- Improved repeated shell switching for standard Zsh prompts.
- Improved keyboard focus and dismissal in the shared-input session picker.

## Package and verification

- Universal application containing Apple Silicon and Intel executables.
- Deployment target: macOS 12 or later; not every OS or hardware combination is qualified.
- Ad-hoc signed, **without Apple Developer ID signing or notarization**. macOS or managed-device policies may block launch.
- No configured public in-app update channel. This prerelease does not update a stable channel.
- Local launch, sensitive synthetic input, rapid native copy/paste, loopback SSH/SFTP, workspace restoration, default terminal rendering, clear and a native SFTP download were checked on the maintainer's Mac.
- Intel execution, every renderer, VoiceOver, quarantined first launch and broad remote authentication/TUI compatibility are not claimed.

The package includes updated third-party notices. Existing versioned releases remain unchanged.
Do not disable macOS protections to install this application; see [Apple's security guidance](https://support.apple.com/102445).
