## Your terminal. Your servers. One workspace.

RelayDesk brings local terminals, SSH sessions, and SFTP file management together in a focused macOS application. Move between a shell and its remote files, keep several servers in view, and return to saved workspaces without piecing together separate tools.

Built for developers and people who work with remote systems every day, RelayDesk emphasizes simplicity, responsive interaction, and familiar Mac conventions: keyboard shortcuts, system appearance, and Finder drag and drop. It works with your existing OpenSSH configuration, keys, and agent. Core terminal and SSH workflows do not require a cloud account.

This is the official public home for RelayDesk: product information, user documentation, public feedback, and future releases. RelayDesk is proprietary software, free to use. Application source code is not distributed in this repository.

## Features

### Available now

These capabilities are implemented in the current application. **Public downloads are not yet available.**

| Capability | What you can do |
| --- | --- |
| **Local terminals & SSH** | Work locally or connect to remote hosts using your OpenSSH configuration, keys, and agent. |
| **Tabs & split views** | Keep multiple sessions visible, search terminal output, and organize sessions into saved workspaces. |
| **Integrated SFTP & SCP** | Browse local and remote files, upload and download, manage queued transfers, and edit remote files in an external editor. |
| **Connection organization** | Group hosts into folders, mark favorites, and find connections by search. |
| **Everyday productivity** | Use a command palette, saved commands, and session history; send input to explicitly selected sessions. |
| **A familiar Mac experience** | Use standard copy and paste shortcuts, Finder drag and drop, and an interface that follows macOS light or dark appearance. |
